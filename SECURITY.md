# Security policy

This is a personal project maintained by one person, on a best-effort basis. Only the latest commit on `master` is
supported.

## Reporting a vulnerability

Please report it privately with GitHub's **Report a vulnerability** button on the repository's **Security** tab. Do
not open a public issue. Include what you found, how to reproduce it, and what an attacker could do with it.

Scope and the trust model are described in the README's [Security model](README.md#security-model) section.
